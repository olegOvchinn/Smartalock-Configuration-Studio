Follow Me Ergonomics

Let end users save and apply their custom sit-stand desk height via the FS mobile app or handset.

Configure

Would you like to allow Follow Me Ergonomics (FME)?

FME allows end users to save and apply a custom sit and stand desk height via the FS mobile app. This requires the desk's sit-stand motor to be integrated with a Floorsense handset — once wired up, the height can be set either from the mobile app or directly on the handset. Choose how you'd like to roll this out, or skip it if you won't be using it.
