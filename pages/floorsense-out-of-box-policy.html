Desk Allocation Method

Edit
Reservation types Reserved by User as Needed

How desks get allocated: users can reserve any available desk themselves, whenever they need one.

Prebooking & Duration

Allow booking in advance 8 days in advanceEdit

Users can book a desk up to 8 days ahead of time.

Default reservation duration 8:30 AM – 5:30 PM (9 hours)Edit

If someone books without choosing a time, their reservation defaults to starting at 8:30 AM and lasting 9 hours (until 5:30 PM).

Check-in Window

Edit
Check-in window60 min before – 60 min after

End users can confirm (check in to) a desk booking at the desk starting 60 minutes before the reservation's start time, and no later than 60 minutes after it. Example: for an 8:00 AM booking, check-in is available from 7:00 AM through to 9:00 AM.

Check-in Behaviour

Second swipe checks out

When on, the first card swipe at a desk checks the user in and a second swipe checks them out. When off, a single swipe checks the user in and the desk is released some other way.

Auto-cancel when checking in elsewhere

When on, if a user already has a reservation for one desk but checks in at a different desk, their original reservation is automatically cancelled.

Access Methods

Edit
Enabled methodsCards · App · Desktop

Building access cards, the Floorsense mobile app, and the desktop app are all available out of the box. Wallet pass is available too, but as a paid add-on it isn't enabled by default.

Additional Options

Maximum desks per user desks

The most desks a single user can have reserved at the same time. Applies to everyone by default — a Desk Group or User Group policy below can set its own, different limit, and a User Group's limit always wins if a user belongs to both.

Auto-Release on Idle Off by defaultEdit

Not part of the fixed defaults — this optional feature automatically frees up a reservation if the desk isn't checked into in time. Enable and configure it from Optional Features if required.

No Swipe No Power (NSNP) OffEdit

Requires an NSNP relay unit to function. Powers a desk off until someone checks in.

Sit-stand desks OffEdit

Sit-stand desk integration is disabled by default.

Recurring bookings

When on, users can set up repeating reservations that book the same desk on a regular schedule. Off by default.

Remote Booking Confirmation

When on, users can confirm their booking remotely with a tap, any time, instead of checking in at the desk itself. Off by default.

Privacy

When on, users can set a Do Not Disturb status to limit interruptions. On by default.

Configured Separately

TeamsSubject to creation

Team groupings aren't set up out of the box — these are created separately when needed.

Book on BehalfSubject to creation

Delegated booking (one person booking for another) isn't enabled out of the box — set up separately if required.

NotificationsSubject to creation

Notification rules aren't configured out of the box — set up separately based on your preferences. Not all notification types can be configured; check with the Smartalock team first.

Additional Policies

You told us you'd like different booking policy for specific Desk Groups and/or User Groups. Duplicate the core policy above under a name like "Finance" or "Help Desk," then adjust it — up to 3 additional policies.

Each additional policy starts as an exact copy of the core policy shown above. Changing a setting here only affects that named policy — the core policy and any other additional policies stay untouched.

User Group settings take precedence over Desk Group settings. For example, if a Desk Group's policy allows 1 desk per user but a User Group that person belongs to allows 15, that user will be able to book 15 desks — the User Group setting wins.
