Auto-Release on Idle

Optionally free up desks that were reserved but never actually used — off by default.

This is an optional feature, off by default. If turned on, a desk that sits unclaimed or unused for long enough is automatically released back to general availability — drag the pin below to set how long a desk may sit idle before that happens.
