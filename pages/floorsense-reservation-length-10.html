Default Reservation Length

When a user self-assigns a desk, how long should they be able to keep it for? Note that Auto-release on Idle may release the reservation before this time if that feature is enabled, and that if prebooking is enabled the user can set the desired length of their booking to override this default.

Free text — this can be any fixed rule, not just a duration (e.g. "until the end of the week").
