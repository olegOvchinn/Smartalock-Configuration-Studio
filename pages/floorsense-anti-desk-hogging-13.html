Would you like to enable Anti Desk Hogging?

Floorsense has a feature to restrict users from booking the same desk multiple days in a row. Some customers enable this to encourage cross-team interaction and to prevent a return to a quasi-fixed-desk way of working. It works by setting a time window — e.g. 2 days — and the number of times within that window a user can book the same desk.

This would allow a user to book the same desk once every 2 days.
